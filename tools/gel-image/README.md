# 胶图处理

入口 `/tools/gel-image/`，首页“我的工具”和账户中心均有并列入口，复用站点的服务器验证登录门禁。图片处理完全在浏览器的 Worker 中进行，不调用本机服务、不上传原图、不写入云端文档。

## 功能

- 多图独立编辑，灰度、反相、亮度/对比度、任意角度旋转。
- 右侧顶部图标切换“调整 / 裁剪 / 编号 / 横向”，一次显示一组工具；再次点击当前图标或右上角 × 可收起。拖动右栏左边缘调整宽度，双击恢复默认；聚焦边缘后可用左右方向键微调、Home / End 调至最小 / 最大。宽度偏好仅存本机浏览器，不包含图片；窄屏自动改为画布下方的工具面板。
- 点击“图上裁剪”后直接拖动鼠标框选；框选后可框内移动、四角缩放、框外重选，支持百分比坐标和固定比例。旋转和裁剪清除当前图的标注位置，横向文字保留。
- 标签范围解析、已知数量的自动泳道定位、等距定位、辅助线拖动/补加/删除。
- “横向”面板：从上到下逐行填写左侧样品信息、右侧 kDa；同一行共用一个高度，某一侧可留空（保留空行可单独标记另一侧）。文字支持空格，kDa 数值及单位需自行填写。自动定位按信息行数寻找不等距的横向条带，也可等距定位，再上下拖动横线校正、补加或删除定位线。识别 Marker 可把左右识别范围缩至 Marker 泳道。自动定位只识别信号位置，不推断分子量；弱信号、倾斜条带、不均匀背景和过密条带需人工核对。
- 左右文字放在图外新增白边，靠近上下边界时补足留白，避免遮挡或截断；可与顶部泳道编号并用。PNG、剪贴板、TIFF、PDF 和处理记录均包含横向信息；PDF 保留文字，TIFF 的源图区域仍按原处理后位深写入。旋转或裁剪后清除横向位置，文字保留，须重新定位再应用。
- 统一的“应用修改”步骤；未应用或仍在图上编辑时阻止导出。
- PNG、8/16-bit TIFF、带文字编号的浏览器 PDF 打印页、带 SHA-256 的 JSON 处理记录。
- “复制图片”将当前已应用的图片及编号以 8-bit PNG 写入剪贴板，可粘贴到 PPT/文档；权限不足时明确提示，不改变编辑内容。
- `.gelwork` 项目保存原始文件及各图已应用/未应用参数。恢复时校验原图 SHA-256，全部成功后才替换现有工作区。
- 新保存项目为 v2，包含左右文字及横向位置；本工具兼容读取 v1 旧项目。v2 项目需要新版工具打开，避免旧版静默忽略横向信息。
- 未保存时打开项目或点击返回首页，会提供“保存后继续 / 不保存 / 取消”。取消文件保存或写入失败不会替换当前项目；下载回退需要用户确认文件已保存后才清除未保存提醒。

最多 8 张图、单图最多 2400 万像素、总源像素最多 3200 万；单文件最多 256 MiB，可重新打开本工具最大尺寸的未压缩 TIFF。项目原文件总量最多 115 MB，项目文件最多 160 MB，过大时保存前明确拒绝，不影响当前编辑。旋转后的外接画布、增加标签后的输出也有像素限制。高分辨率 16 位处理需要较多内存，请使用桌面浏览器并分批处理。

TIFF 支持单页条带格式、无符号灰度/RGB 8/16-bit、无压缩/LZW/Deflate/PackBits及水平差分预测。明确拒绝多页、BigTIFF、浮点、分块、分离通道、无明确 alpha 标记及非标准方向标记。输出为无压缩、非预乘 RGBA TIFF，不保证保留仪器元数据、ICC 等。16-bit PNG 会明确拒绝并建议先转换为 16-bit TIFF；其他 PNG/JPEG 输入走浏览器的 8-bit 解码路径；PNG/PDF 为展示输出。请保留原始仪器文件用于定量。

## 实现来源

`core.mjs` 依据用户提供 GelFlip 发布包的静态反编译结果移植。保留处理顺序、16 位通道、取偶舍入、alpha 插值、泳道采样与已知数量定位逻辑；补充无效输入、极端长宽比和项目校验。`tiff.mjs` 为网页实现的基础条带编解码器。没有分发原 EXE/DLL、原安装脚本或系统证书。字体度量由浏览器完成，不宣称与 WPF 逐像素一致。

## 验证

```sh
node --test tools/gel-image/tests/core.test.mjs
node --check tools/gel-image/app.mjs
```

完整 TIFF 独立交叉检查：用开发环境的 Pillow 运行 `tests/generate_fixtures.py <输出目录>`，设置 `GEL_FIXTURES` 为该目录，再运行上述测试。16 份夹具涵盖灰度/RGB、大小端、8/16 位及四种压缩。

浏览器验收：`node tools/gel-image/tests/browser.cjs`，需要 Playwright 和 Edge。可用 `GEL_PLAYWRIGHT_PACKAGE` 指定含 Playwright 的 package.json，`GEL_FIXTURES` 指定夹具，`GEL_TEST_OUTPUT` 指定结果目录。脚本自建临时本地服务器，先核对真实门禁阻止匿名加载，再仅在 loopback 测试上下文中替换门禁模块以测试编辑器，不包含生产绕过入口。

不自动保存：关闭/刷新前须保存项目。当前不接入云端图片或项目同步。新增 JS/CSS 不需要额外构建；站点现有 GitHub Pages 构建会发布已跟踪的工具文件，并排除测试、Python 和本说明。

关闭标签页、刷新、浏览器后退等使用浏览器原生的“离开 / 取消”提醒；浏览器不允许网页在该提示里添加保存按钮。选择取消可返回页面保存。`GEL_WORKFLOW_ONLY=1` 可单独验收离开保护、文件保存取消/失败和图片剪贴板；剪贴板验收仅使用合成演示图，并逐像素比对同状态 PNG 导出。

`GEL_PANEL_ONLY=1` 单独验收工具图标切换、编辑状态保留、面板收起、宽度拖动与键盘调整、宽度记忆和窄屏布局。

`GEL_ROWS_ONLY=1` 验收横向自动定位、拖动/补加/删除、左右文字及顶部编号组合、项目 v1/v2 恢复与损坏字段拒绝、剪贴板与 PNG 逐像素一致、PDF 文字，以及带左右标注的 16-bit TIFF 源图像素保真。
