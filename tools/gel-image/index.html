为展示保留清晰，为实验保留原始。

原始数据请另行保留用于定量。PNG / PDF 为 8-bit 展示图；16-bit TIFF 可保留处理后的位深。

从一张原图开始

  1. 打开图片，确认是否需要反相。先旋转校平，再裁剪。
  2. 输入实际上样顺序，例如 M,1-6,M 为 8 道。标签内部不要使用空格。
  3. 自动定位或等距定位后，拖动辅助线逐道核对。自动定位不识别样本身份。
  4. 点击“应用修改”，确认预览后导出。未应用的修改会阻止导出。
  5. 保存 .gelwork 项目会包含原图文件和各图参数，下次可恢复编辑；图片和项目不会上传。

TIFF 支持常见条带格式：无压缩、LZW、Deflate、PackBits，灰度/RGB 无符号 8/16-bit。多页、浮点、分块、分离通道及非标准方向 TIFF 会明确提示，避免误读。

打印 / PDF 将打开浏览器打印页，请选择“另存为 PDF”。导出图片含合成编号；PDF 编号使用文字。处理记录包含原图 SHA-256、参数和重采样标记。工具不提供条带定量。

图片仅保存在当前页面内存中，不自动保存到浏览器。请及时保存项目和原始数据。
