# Life Atlas

科研实体生命周期与谱系管理工具。开发预览已发布于 https://blackblues.xyz/tools/life-atlas/ 。当前版本包含项目分组、标签、多盒与位置历史。需求与 UI 原件保存在 `docs/development/life-atlas/`，完整 V0.2 基线及实现边界见该目录下的 `implementation.md`。

已支持小鼠基础档案与实际年龄、细胞系与培养批次关联、培养条件继承、档案修订前后快照和分型结果历史。项目页支持分组体重 / 肿瘤测量对比、原始测量 CSV 与原始事件追溯；测量归属使用发生时的成员有效期。右侧详情和表单可点击左侧空白处关闭。三类实体页面均使用卡片切换时间轴；保留旧版已计时细胞系的实际生命周期。本轮新增上下游谱系 PNG 导出；126 项业务测试、56 组浏览器流程通过。

从仓库根目录运行 `python scripts/serve.py --port 8765`，浏览器打开 `/tools/life-atlas/`。沿用网站登录服务；需已配置且有效的网站账户。无需额外安装或构建。

细胞、样品、小鼠页均以 170×40px 紧凑卡片切换时间轴，不显示实体下拉框；新建、记录及小鼠批量操作与卡片同行，窄屏时排在卡片下方。细胞显示正在计时的培养实体，样品显示未结束的可用样品（包含保存单位），小鼠显示在管个体；历史与未计时档案仍可从“全部档案”列表点击进入。

“位置与存储”支持直接登记已有冻存管，无需先补录培养历史。空库点击存入或空格位会打开库存登记，也可使用“登记已有冻存管”按钮。每支管独立占位，支持原管号、细胞系、冻存日期、P 数、数量单位、冻存液与来源；P 数 / 日期未知可留空。登记与实际冻存分开记录，复苏后才开启培养 D0，未知 P 数在衍生流程中保留未知。

“批量导入库存”支持 CSV / TSV 上传或从 Excel 粘贴清单，提供空白 CSV 模板、自动 / 手动字段对应、目标盒与可选所属细胞系、问题行预览、返回修改及确认后整体追加。表格每行一支管，可对应格位或分开的行 / 列，也可通过盒路径列导入多个已建档细胞盒。重复管号、文件内重复格位、现有占用及非法字段会阻止保存；可显式跳过已填信息一致的已有记录，其他冲突不覆盖。导入保留批次、文件名与源行号，可幂等重试，JSON 恢复校验批次完整性。每次最多 500 支、文件不超过 2 MB。直接 .xlsx / .xls 文件及按盒排布的二维网格导入尚未实现；Excel 请复制含表头的清单或另存为 CSV。文件编码支持 UTF-8、GB18030 / GBK 和 UTF-16。

“基本信息”或实体详情中的“导出报告 / PDF”可选择当前实体、全部上游、全部下游或两者，设置是否包含备注及计划。先预览，再点击“打印 / 保存为 PDF”，在浏览器打印窗口选择“另存为 PDF”。报告包含生成时间（北京时间）、研究空间、数据修订、当前档案、全部生命周期、原始事件与追加修正、存储历史、范围内的谱系关系及小鼠测量明细。计划单列，不混为实际事件；共享输入材料可在事件中追溯，不自动扩展为谱系档案。生成报告不改动本地数据。当前支持实体报告、存储清单和实验项目报告；项目概览 PNG 导出仍待开发。

“位置与存储 → 导出清单 / PDF”支持当前盒或全部盒，导出 CSV 或先预览再打印保存 PDF；清单可选空位和档案备注。PDF 布局始终包含全部格位，最大 26×26 样品盒拆为不超过 9×9 的分区，多盒各自起页。记录只包含当前实际占用，不混入已取出 / 复苏 / 结束的单位；实际冻存日期与当前位置存入时间分开，未知日期及 P 数不推算。CSV 保留单位、北京时间时区、所属细胞系、冻存液、来源，以及库存导入文件与原表行号，并防止表格公式注入。导出不修改原数据或补建旧历史。大批量 / 大数据性能尚未验收。

“小鼠管理 → 实验项目与分组 → 导出项目 / CSV”支持所选项目全部分组或指定历史分组。可下载包含全部成员期或仅当前成员的 CSV，或预览包含当前成员、转组历史、体重 / 肿瘤个体曲线和原始测量、实验事件与追加修正的报告，再打印保存 PDF。项目说明、成员变更原因和事件备注可选隐藏；测量和事件明细可选省略。归属按事件发生时的成员有效期确定，明确关联其他项目的事件不混入；修正链随原事件保留，退出或转组不会改写旧组数据。保留原始数值，不换算异常单位，不计算组均值或误差；成员档案为当前快照，仍有效的成员关系与仍在管个体分开计数。导出只读，不写入数据库。

“位置与存储 → 导出清单 / PDF → 当前盒格位 PNG 图片”可直接保存当前盒全部格位的图片，可选编号、实际冻存 / 存入日期和档案备注。图片包含盒路径、研究空间、生成时间与占用数，长文字自动换行；支持最大 26×26 样品盒。PNG 当前仅支持单盒，全部盒请用 PDF / CSV。图片高度超过 16000 像素或总像素超过 3200 万时会阻止生成并提示关闭备注或改用 PDF。编码完成后再次核对账户身份；只读导出不改变数据。

“小鼠管理 → 实验项目与分组 → 分组测量对比 → 导出测量 PNG”可选择历史分组和体重 / 肿瘤测量，选择是否包含小鼠编号和测量日期。曲线按实际时间比例排列，跨成员期或生命周期不连线；原值有追加修正时显示星号，不自动重算。只纳入单位和数值有效的记录，不换算、不补值、不计算均值或误差；无有效记录时阻止导出。图中不含事件备注，生成后核对账户身份，导出不写入数据。

三类实体的“基本信息 → 导出时间轴 PNG”可保存当前实体全部参与事件的纵向图片，可选实体 / 事件编号、公历时间、D+ / 保存期、事件备注及直接衍生分支。保留原始生命周期位置、参与角色、原事件与追加修正，不将兄弟实体视为自身分支，不把计划当实际事件。按发生时间排序，间距随文字内容调整，不代表真实时间比例；生成时不重新计算历史状态。超长图片提示隐藏备注 / 分支或改用 PDF，编码后核对账户。当前只支持单实体与直接衍生说明，上下游谱系图 PNG 另有导出入口。

“基本信息 → 导出谱系 PNG”支持当前实体、全部上游、全部下游或上下游，使用当前档案绘制来源层级；可选编号、当前 D+、当前生命周期及来源事件日期、档案备注。会合节点只画一次，保留全部范围内来源边，跨层连线绕开中间节点，并提供节点 / 关系索引。不会扩展兄弟分支或后代其他来源；图外相邻关系计数另作提示，共享输入参与不画成谱系边。横向不表示时间比例；有环、范围错误或图片过大时阻止生成，提示核对数据或缩小范围 / 改用 PDF。导出只读，编码后再次核对账户身份。

入口已经加入首页工具列表及账户中心导航。演示空间与个人数据库分离；正式数据按账户 ID 保存在本机 IndexedDB。云备份尚未实现，请导出 JSON。
