# SOP Timeline Editor

面向实验人员的双泳道 SOP 时间轴编辑器。独立静态网页，不使用账号、服务器数据库或第三方运行依赖。入口：`https://blackblues.xyz/tools/sop-timeline/`。首页页脚提供入口。

## 运行与部署

在仓库根目录运行 `python -m http.server 8000`，打开 `http://localhost:8000/tools/sop-timeline/`。需要现代 Windows Edge / Chrome。不要直接双击 HTML，浏览器会限制本地模块加载。

无需安装依赖或构建；本目录的 HTML、CSS、SVG 和 `.mjs` 就是可部署产物。现有 GitHub Pages 工作流在 `main` 更新后发布整个网站。也可以将本目录完整复制到其他静态服务器的子路径；资源均使用相对引用。

## 使用

1. 新建空白 SOP，或使用首次打开时的可编辑示例。实验名称为可直接编辑的大标题，“SOP 实验流程”为小副标题。点击作者、日期和大步骤标题修改。
2. 等待泳道在左，操作泳道在右。将左侧等待块 / 操作块拖入对应泳道。参考线显示合法端点；位置冲突时显示红色反馈。点击组件也可以添加到当前大步骤。
3. 点击时间输入 `5 min`、`30 min`、`2 h`、`30 s`。拖动块底部手柄调整尾端；头端固定。直接编辑右侧实验文字，选中文字后使用 B / I。
4. 文字区只保留自由输入，不显示对象、材料、环境等附加字段。同时开始的两段文字并列且顶端对齐。长文字在输入时自动增加显示空间，不增加真实时间。
5. 将“环境块”拖到最右侧环境区，从词条中选择，默认只覆盖落点所在的最小时间区间。拖动顶部 ↑ 或底部 ↓，可分别扩大、缩小环境范围，吸附当前大步骤中两条泳道的全部时间节点；例如 90 分钟等待中的一段 5 分钟操作。调整环境只改变标注，不移动时间块、文字、备注或布局。相邻环境块不会重叠，手动范围保持独立。点击环境名称可更换词条或移除标注。右侧设置可以添加、删除环境词条；删除词条不会清除已用标注。词条与环境范围随草稿和 `.soptime` 保存，新建 SOP 沿用当前词条。
6. 拖动大步骤标题旁的 ⠿ 调整分组顺序。一级容器包含块、文字和备注；折叠不影响时间计算或导出。点击 × 立即删除整个大步骤及内容，后续时间自动闭合；Ctrl+Z 一次恢复，不需先清空内容。
7. 单击块选择；Ctrl C / V、Delete 管理块，Ctrl Z / Y / Shift Z 撤销与重做。文字编辑时保留浏览器原生文字撤销。Ctrl S 保存；Ctrl Shift S 另存为。Ctrl + 滚轮缩放，空格 + 鼠标拖动画布。
8. 保存 `.soptime` 原始文件；“打开”完整恢复可编辑数据。Edge / Chrome 支持选择保存路径和覆盖保存，其他浏览器会下载新文件。自动草稿只存在当前浏览器和域名，最多保留 100 次本次会话的撤销记录。清理浏览器数据会清除草稿。
9. PNG 导出完整时间轴，通常为 2× 分辨率，超长图自动降低倍率并提示。PDF 使用独立 SVG 矢量打印排版，点击导出后在浏览器选择“另存为 PDF”；A4 自动分页，建议关闭浏览器页眉页脚。打印不含工具栏、选择框或手柄。

## 数据与时间算法

`core.mjs` 是独立于界面的模型层，时间以整数秒保存：

```js
{
  version: 1, name, author, date, revision,
  groups: [{ id, title, collapsed }],
  blocks: [{ id, group, lane: 'operation' | 'wait', start, duration,
             text, object, environment }],
  notes: [{ id, group, text }],
  environmentTerms: ['室温', '冰上', '4°C', '37°C'],
  environmentRanges: [{ id, group, start, end, environment,
                        startAnchor: { blockId, edge: 'start' | 'end' },
                        endAnchor: { blockId, edge: 'start' | 'end' } }],
  layout: { operationWidth, waitWidth, laneGap, environmentWidth,
            fontSize, spacing, theme, orientation }
}
```

`start` 与 `duration` 表达可重新计算的关系，结束时间为二者之和。总耗时为最大结束时间，绝不累加并行块。新块至少一端吸附已有端点，可以头对头、尾对尾或头尾衔接；允许 5 分钟操作与 30 分钟等待从同一头端开始。

尾端伸缩先在原快照中，从旧尾端收集所有以该节点为头端的后继，再递归收集后继的后继。选中块只修改 duration，后继整体平移相同 delta，同尾端结束的其他块保持原位。算法遍历端点交叉的临界值和硬上限，限制在从原值连续可达的最近合法秒数，防止穿越冲突。其他块 duration 保持不变。

每次操作统一校验：正时长、同泳道不重叠、全局从 0 连续覆盖、大步骤不交叉。删除先移除块，再将全局空洞之后的后缀整体左移以闭合；移动先删除闭合，再吸附插入，必要时平移插入点后的块。安全校验失败时不提交修改。当前规则下合法时间轴的普通删除总能通过后缀闭合；没有人为增加“不能删除”的额外限制。

大步骤排序保留内部相对时间和所有块的原时长，按容器包络依次重排。备注和环境范围随容器移动。

环境范围独立保存在 `environmentRanges` 中，范围边界引用现有时间节点并保存端点锚点。`resizeEnvironmentRange` 只修改该数组，不进入时间块联动算法或视觉高度计算。时间块或大步骤发生调整时，锚点同步范围并限制在组内；删除步骤不会留下悬空标注。旧文件缺少该数组时，由旧环境属性一次性迁移；显式空数组表示已移除所有环境，旧属性不会重新生成标注。

`groupLayout` 将唯一真实端点映射为共享纵坐标，长区间采用对数压缩和最小高度。界面再测量文字实际高度调整这张映射；两泳道始终共用映射。打印使用同一时间数据，独立计算换行和分页；过长单段文字按安全行间拆分并标注“续”。

导入检查版本、ID、类型、大小与时间合法性，限制布局数值；富文本只显示基础加粗 / 斜体，其他 HTML 不执行。未来格式迁移入口位于 `importDocument`，当前不接受未知版本，防止损坏数据。

## 验证

Node.js 18+：

```sh
node --test tools/sop-timeline/tests/core.test.mjs tools/sop-timeline/tests/environment.test.mjs
node --check tools/sop-timeline/app.mjs
node --check tools/sop-timeline/export.mjs
```

浏览器端需开发环境安装 Playwright 和 Microsoft Edge，仅用于测试，网页运行不加载这些依赖。启动上述静态服务器后运行：

```sh
node tools/sop-timeline/tests/browser.cjs
node tools/sop-timeline/tests/environment-browser.cjs
```

可使用 `NODE_PATH` 指向现有 Playwright 包目录，`SOP_TEST_URL` 设置测试服务器，`SOP_TEST_OUTPUT` 设置截图、PNG、原始文件与 PDF 的输出目录。默认输出到系统临时目录。

V1 实测：36 项模型测试通过；完整浏览器套件和环境范围专项均通过。专项实际拖动上下手柄，将 90 分钟等待内的环境缩成 5 分钟，并比较其他内容的文档数据和 DOM 几何位置均保持不变，覆盖扩大范围、取消后预览及撤销栈恢复、撤销重做、保存重开、旧稿迁移、最小区间拖入、PNG 像素范围及 PDF 矢量边界。原有双泳道、空容器插入、整组删除、文字编辑、文件往返和 8 页中文 PDF 验收继续通过。

## V1 限制

- 优先支持 Windows 桌面 Edge / Chrome；鼠标拖拽为主，尚未专门适配触屏操作。
- 仅一级大步骤；大步骤之间按顺序执行，不支持跨容器重叠。没有额外的锁定步骤或依赖关系编辑器，起点等于旧尾端即视为后继。
- 每块时长最多 7 天，时间轴最多 70 天；最多 1000 块、200 个容器、5 MB 原始文件。超大流程建议拆分，伸缩的临界点计算优先保证正确性，极大数据尚未做性能优化。
- 环境上下边界限制在当前大步骤的既有时间节点之间，最小为相邻两个节点间的区间；不支持任意秒数偏移或跨容器拉伸。旧文件的对象数据保留兼容，界面和导出不显示对象字段。
- A4 PDF 需通过浏览器打印界面保存。PNG 以完整性优先，特别长的流程会降低倍率，超出浏览器安全尺寸则提示改用分页 PDF。
- 文件内容和浏览器草稿均不上传。示例不代表经过验证的实验参数，使用者应按确认的实验 SOP 填写。
