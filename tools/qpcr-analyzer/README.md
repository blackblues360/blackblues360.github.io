# qPCR Analyzer · Phase 0–3

独立的 React + TypeScript + Vite 本地实验工作台。侧栏包含实验信息、实验准备、孔板设计、数据导入、质量控制、定量分析、统计与图表、日志与版本八个页面。原始数据存储在当前浏览器。

## 启动

Windows 双击 `start.cmd`，或在本目录运行 `npm ci`、`npm run dev`。使用启动终端显示的地址（默认 http://127.0.0.1:5178/ ）。生产构建用 `npm run build`，静态产物在 `dist/`；需通过 HTTP/HTTPS 提供，不能直接双击 index.html。

IndexedDB 按访问地址保存项目；刷新后自动打开最近保存项目。换网址、端口、浏览器或清理浏览数据前导出 `.qpcrproj`。保存失败会明确报错，不报告已保存。并发页面的陈旧写入会被拒绝；此时重新打开项目读取最新状态。

## 已实现

- 统一项目与数据模型、IndexedDB、原始文件 SHA-256、完整项目打包/恢复、方案模板、追加式哈希日志、分析版本快照和恢复。备份恢复为独立副本，避免覆盖原项目。
- QuantStudio 7 Flex EDS/XML/多行分析结果、XLSX 四表自动识别；保留原始 Ct、仪器 Omit、分析参数及内部文件；原始滤光通道、Rn/ΔRn 和熔解曲线读取。解析在 Web Worker 执行。
- 同一实验的两个文件按孔位/样本/Target/Ct/Tm/所有扩增与熔解点交叉验证。容差 0.0001；不一致阻止合并并记录完整差异，完全相同文件跳过。只分析一个活动来源，两个文件不会使孔数翻倍。
- RNA/RT、可编辑温度程序、qPCR、逐 Target Master Mix、低体积及不足检查，CSV 配液导出。默认 SOP 参数可编辑，包括总体积、稀释、额外比例、QC、板规格、方向；在高级参数 JSON 中应用。
- 每样本 Target 子集、每 Target 技术重复数、按行/列相邻自动排板、多板拆分、手动/多选分配、拖动交换、控制孔。设计布局和分析孔位重新映射为两个明确操作，原始数据始终保留。
- 缺失/异常 Ct、技术重复 SD/Range/n、NTC/No-RT 阳性、曲线启发式检查；异常不自动排除，人工排除必须填写理由。仪器 Omit 自动不纳入。
- 技术重复算术平均、多内参 Ct 均值、单生物学样本或对照组校准、ΔCt/ΔΔCt/2^-ΔΔCt、定量 CSV。生物学 ID 不允许跨组复用。Ct 尺度不输出 CV；不把技术孔作为统计样本。
- 单孔/多孔扩增、熔解 Rn 与导数曲线、分页原始表、仪器原始参数查看。配液变化只更新用量，定量参数、分组、映射、纳入孔变化生成新分析版本。
- 按靶标汇总各组 Fold Change 的样本数、均值与 SD，显示组均值及样本散点，支持导出 SVG 和 Excel。

## 使用真实实验

1. 新建项目，同时选择 EDS / XLSX。核对 12 Samples、8 Targets、90 有效孔、40 循环、181 熔解点和交叉验证结果。
2. 在实验准备页确认生物学 ID、分组、控制孔与 RNA 浓度。不根据样本名称自动推断分组或对照类型。
3. 保留导入孔板用于原实验配液，或修改配置重新设计下一次实验；变更设计布局不直接重写仪器映射。分析重新映射使用单独按钮。
4. 在 QC 与定量页指定内参、校准样本/组。只有人工确认扩增效率适用前提后才输出 Fold Change。效率记录仅留档，不代表本版本已做 Pfaffl 校正。
5. 查看 QC 提示和原始曲线，按理由决定排除。每次相关更改自动保存分析版本；日志与版本页可查看参数和恢复。
6. 导出完整项目备份、配液 CSV 或定量 CSV。

## 范围与限制

- 统计页目前提供描述性汇总。推断统计、显著性标注与出版级报告属于后续阶段。
- EDS 适配仅以提供的 96 孔 QuantStudio 7 Flex 文件验证；其他仪器/软件版本、同孔多 Target 尚不支持。XLSX 没有滤光通道原始信号。曲线 QC 为可配置启发式提示，不能代替人工曲线检查；尚无自动基线/阈值叠加或独立 Ct Calling。
- 项目备份绑定解析器 0.1.0。导入校验原始文件并重新解析对照；后续解析器升级需要添加显式迁移。哈希校验用于意外损坏检测，不提供签名或防恶意篡改的保证。
- IndexedDB 配额、隐私模式、浏览器清理会影响本地存储；导出项目是跨电脑迁移与独立备份方式。
- 常用 RNA、RT、配液与孔板参数可在页面上编辑。RT 程序和质控阈值等参数位于「实验准备 → 高级参数」。
