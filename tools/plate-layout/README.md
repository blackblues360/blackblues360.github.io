# 孔板原始方案备份与恢复

“备份 JSON”导出当前完整 v1 编辑状态；PNG/JPG 仍用于图片输出，不能用于恢复模型。

导入仅接受结构可确认的 v1 原始方案（plate.type/title、wells、labels，ui可缺省）。先校验文件及5MB大小限制，再保存当前编辑状态和原始存储文本，随后显示板型、标签/已分配孔位数量与字段规范化前后差异。可分别下载导入原文与规范化预览；只有点击确认才写入主方案。未知版本或无法安全识别的稀疏/损坏结构会被拒绝，原文件保持不变。

导入后可撤销/重做，或刷新后使用“恢复导入前备份”。“导出导入前备份”下载包含storageText（原存储文本）与state（编辑快照）的备份包；这是恢复证据包，不是可直接导入的原生state。恢复按钮恢复编辑快照，不把坏的storageText重新写入主键。

主存储键仍为 `blackblues.plate-layout.v1`，最近一次预览前备份位于 `.import-backup`；先前备份保留在附加随机ID的键下，不自动删除。存储失败会中止导入/恢复，不清旧方案。备份占用本机容量，需要自行下载留存；完整备份历史管理暂不提供界面。

预览确认与恢复会检查已观察到的其他页面存储变化，但localStorage没有原子CAS；正常编辑也未加入多页面协同锁。避免同时在多个标签编辑同一方案。这不是云端同步功能。
