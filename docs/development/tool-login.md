# 工具登录入口

首页导航、账户登录/邀请/恢复入口公开。所有发布的 `/tools/` HTML 必须通过统一入口初始化；缺少保护或仍包含直接启动脚本时，白名单构建失败，不会把新工具意外公开。

工具 HTML 的 html 标签增加 `data-tool-page`，head 引入 `../../assets/css/tool-access.css`，原 `app.mjs` 模块标签替换为：

```html
<script type="module" src="../../assets/js/account/tool-access.mjs" data-tool-entry="app.mjs"></script>
```

body 中保留 `#toolAccessGate` 登录提示，含 role=status、data-tool-login 链接和重试按钮。可复用现有工具的完整节点。不要另加内联/直接启动脚本绕过统一入口。`../../script.js` 仅处理主题与导航。

入口验证服务器上的当前登录用户后才加载工具模块。未登录不初始化编辑器、不读取工具草稿。验证失败保持关闭，可重试；退出时立即隐藏工具，换账户后重新加载，避免上一账户页面继续使用。登录返回路径只接受本站 `/tools/` 地址，拒绝外站跳转。

本机草稿与云端文档仍分开保存，登录不会自动上传或删除原件。旧匿名浏览器回归应先在隔离本地 Auth 中登录，再验证工具操作；不能为通过旧测试而在产品中关闭访问检查。

这是静态站的页面使用限制，不能把公开的 HTML/JS 变成服务端私有文件，不能承诺阻止人为修改浏览器代码后离线运行。云端数据继续由 Supabase RLS/RPC 验证实际身份；如需源码及全部静态资源也不可匿名访问，需要另行部署带服务端认证的托管入口。
