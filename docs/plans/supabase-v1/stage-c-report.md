# 阶段 C 验收报告

日期：2026-10-30。结论：孔板/SOP 云端管理、统一回收站、安全导入和异常恢复已在本地实现并实际验证，可以进行代码与正式部署前审核。**尚未完成正式发布验收**；阶段 C 新迁移没有部署正式库，不能将本地结果称为线上功能已上线。

## 1. 已完成的功能和关键保护

两个工具复用统一 Auth 和 `tool_documents`，提供新建、列表、加载、名称修改、手动保存、软删除、统一回收站、恢复及永久清空正文。登录后检查本机方案并提供核对入口，不自动上传。游客编辑与原有文件能力保留，未重写两个编辑器。

公共模块 `documents.mjs` 负责数据访问，`document-manager.mjs` 管理文档与保存状态，工具适配器负责完整内容校验、编辑和文件格式。创建请求不携带 user_id；数据库使用 auth.uid 默认归属及 RLS。更新、删除、恢复、永久删除都核对 expected_revision，冲突不读取最新 revision 自动重试。

保存明确区分未保存、保存中、成功、失败、冲突、离线。发送前固定完整快照，成功响应只更新该快照的 revision；保存期间的新编辑和未失焦 SOP 时间输入保留为未保存。只有实际成功才显示云端已保存。断网后不自动提交，恢复网络仅提示手动重试。

创建采用稳定 UUID 和发送快照。超时重试核对同 ID 的 app/version/title/content/revision，不能把后续编辑假装成原创建结果。无法可靠写入本机缓存时，首次创建前要求用户导出含 UUID/发送快照的恢复文件。

缓存按 UID/工具/文档 ID 隔离，沿用 Web Locks 和快照保护；拿不到锁时仍可通过 CAS 保存云端，但本机缓存改为内存/独立恢复文件。账户切换保存原账户草稿、取消请求、恢复游客界面，旧结果不能写进新账户。已有公共请求层将启动请求时的 JWT 固定在请求头，实测异步取 session 时切换账户也不会改用新账户身份。

无锁内存草稿在返回本机、A/B/A 切换后仍可恢复；从正常云端列表重开同 ID 时也先询问恢复，取消则停止打开并保留唯一草稿。没有可靠存储时，关闭整个页面仍可能丢失内存，界面提示独立导出和离开提醒；不承诺浏览器崩溃时必然弹窗。

## 2. 孔板和 SOP 的本地数据保护

孔板继续支持四种板型、选择、标签、颜色、撤销、PNG/JPG，以及阶段 A 原始 JSON 导入导出。文件导入保留原始文件、规范化预览及最终状态的区别。处于云端模式时，JSON 文件导入为独立新草稿，不覆盖原云端 ID；确认预览时再核对账户/文档上下文。保留当前工作区已有的新菜单布局，仅调整相应测试入口。

SOP 继续支持块/容器/拖动/环境标注、撤销、`.soptime` 和多页 PDF。损坏本机草稿仍为恢复失败状态，禁止游客自动保存和退出写回；云端有效文档可独立打开，回到本机后原损坏文本仍冻结。损坏或需要规范化的云端内容拒绝加载并可导出原始 JSON 值，不用示例文档替代保存。

本机方案迁移要求显式预览、选择、下载备份、确认。备份包含原 localStorage 文本和实际待导入的完整当前内容；成功后重新读取核对云端，本机原件不删除。JSONB 比较按 JSON 值，不宣传字节级原文件备份。

恢复文件校验 UID/app/id/revision/内容及创建快照的一致性；SOP 未提交输入还检查对应可见块。浏览器拒绝读取 localStorage 时，有效恢复文件仍保留 pendingCreate/inputDraft。恢复 SOP 输入前关闭模态框再恢复焦点，避免旧内容写回覆盖输入；长的有效时间输入不会被 200 字符截断。文件异步读取期间若出现新编辑或切换上下文，拒绝旧结果。

## 3. 数据库变更（仅本地）

新增版本化迁移 `20261030100000_document_recycle_bin.sql`，原正式六份迁移不改写：

- `tool_documents.purged_at` 与对应 CHECK 约束，区分软删除和已清空正文的墓碑。
- `list_deleted_tool_documents` 只返回本人软删除且未永久清空的元数据。
- `restore_tool_document` 核对 UID、所有权、删除状态及 revision，恢复时递增版本。
- `purge_tool_document` 二次确认后由服务端清空正文/名称并递增版本；保留 ID、所有者与墓碑，防止旧 INSERT/UPDATE 复活。
- 撤销 authenticated 对 user_id 列的 INSERT；新增 SECURITY DEFINER 函数内部校验身份，使用空 search_path，撤销 PUBLIC/anon 执行权后只显式授予 authenticated。

永久清空释放正文容量，仍占 1000 文档 ID 名额；这避免无限制造墓碑。界面第二次确认明确提示保留历史名额、既有备份不被删除。回收站暂不自动到期清理，也未创建浏览器或服务端定时任务。纪念日的删除规则不扩展为这两个工具的回收站。

已经用官方 CLI 在隔离本地环境从空库执行全部 7 份迁移，随后执行 pgTAP 与双连接测试。正式库保留阶段 B 的六份迁移，**第七份正式部署待用户审核授权**。

## 5. 已执行但失败，后续修正并通过
