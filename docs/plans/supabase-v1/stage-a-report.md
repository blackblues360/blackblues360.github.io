# 阶段 A 验收报告

日期：2026-10-30。结论：两项工具数据保护已实现；隔离本地 Supabase 的迁移、权限、真实 JWT 和并发验证完成。当前版本可进入正式部署前审核，尚未进行任何云端部署。网站没有接入登录或同步。

## 1. SOP 损坏草稿保护

新增 `tools/sop-timeline/draft.mjs`，明确区分 missing（没有草稿）、restored（正常恢复）、failed（读取/解析/校验失败）。失败时使用空白占位文档，不使用示例作为可保存的恢复结果；编辑区与工具栏设为 inert，自动保存、commit和文件保存入口均有失败态保护。beforeunload仍保留正常保存路径，但失败态不会写回。

恢复面板允许下载原始草稿文本，或选择有效.soptime；重新开始/替换均需用户明确确认。写新草稿前先备份原文，先前的恢复备份另存随机ID键，不静默覆盖。备份/存储失败则中止，原主键不变。恢复时发现其他页面已修改原存储也中止。没有调用removeItem清理现有草稿。

验证包含正常恢复、坏JSON、合法JSON但坏结构、空字符串、失败后合成编辑和关闭页面、原文下载、取消重启、确认新建、有效文件恢复、配额失败、多次备份保留。正常编辑、撤销/重做、原始文件、PNG/PDF回归通过。

## 2. 孔板原始 JSON 数据保护

新增 `files.mjs` 和 JSON 导入/导出界面，PNG/JPG功能保留。流程为：文件上限与v1结构校验→规范化副本→保存导入前原存储文本及编辑快照→展示板型、标签和已分配孔位数量、字段前后差异→用户确认→写入。拒绝未知版本、损坏或无法安全识别的结构，不猜测迁移。

三类数据明确分开：原始文本rawText、restoreState生成的normalized、确认后的编辑状态。预览可分别下载原文和规范化JSON；不把规范化结果称为原始文件的精确副本。当前JSON备份是编辑状态；“导出导入前备份”另外包含原storageText及state快照。

导入失败/取消不改主方案；本机备份失败时拒绝导入，主写入失败时不改编辑状态与历史。成功后可撤销/重做，刷新后也能恢复最近备份。先前备份保留为独立键。导入确认与恢复会检查已观察到的其他页面变更，避免已知的过期状态覆盖。相同状态导入的存储快照也会刷新，避免误报外部变更。

## 6. 已失败尝试及修复

- 初始完整Supabase拉取镜像时，ghcr.io/ECR出现TLS超时和401。切换本次进程的官方Docker Hub源并复用已下载镜像后，完整最小本地服务与官方测试成功；未修改全局网络设置。
- 裸Supabase数据库镜像单独启动时，其初始auth.uid只读取request.jwt.claim.sub，早期仅设置JSON claims的夹具因此被RLS拒绝。已定点确认函数定义；改用CLI完成官方初始化的环境后69项通过。没有为通过测试放宽RLS或修改生产Auth逻辑。
- 便携PostgreSQL最初高位端口被Windows拒绝绑定，后备改为回环15432。早期缺少psql/匹配驱动的问题已通过临时便携依赖解决。
- 孔板新增第4个备份按钮后，原浏览器测试检出390px宽度横向溢出。已为动作区与按钮组补充收缩/换行，最终原浏览器回归通过；没有关闭或删除该断言。
- 相同状态JSON导入后，存储格式变化可能让“恢复备份”误报外部修改。已刷新主写入后的存储快照，并新增第14个浏览器场景验证。

最终验收用例无未解决失败。以上准备/回归失败与修复均保留说明，不混写为从未失败。

## 7. 仍存在的限制

- SQL文档形状检查仍是顶层类型/数量约束，不是完整工具语义验证；不保证阻止所有坏标签引用、时间轴重叠或恶意富文本。工具读入时仍须使用各自校验/安全渲染入口。
- JSONB只验证了语义完整性，不保证缩进、键顺序、重复键或原文件字节一致；原件与原始存储文本独立留存。
- 5MB是入库JSONB文本字节限制，不覆盖HTTP请求体、解析内存或用户总配额。限流和总配额尚未实施。
- 已知其他人的UUID时，唯一键23505可暴露“该UUID已占用”，但不能读取正文。未擅自更改为复合主键。
- localStorage没有原子CAS；当前保护会拒绝已经观察到的外部变更，但未实现多标签协同锁。正常多页面编辑仍可能最后写入覆盖，勿把本地保护当云端并发方案。
- 备份归档不自动清理，可能占用容量；备份失败时保持锁定/拒绝导入，需要下载原文并处理浏览器空间。旧归档尚无完整历史浏览界面，最近备份可直接导出/恢复。
- 软删保留正文和主键，没有回收站界面或自动物理清理。保留期、总配额、闰日/时区等原待确认决策仍有效。
- 生产Auth提供商、邮箱投递、密码找回、OAuth回调、会话撤销、生产备份恢复均未验证。没有开发统一认证页面、纪念日或工具同步。
